# Student Manager

A Java web application built using Servlets and JSP following the MVC architecture.

## Features

- Register Student
- View Students
- Update Student
- Delete Student

## Tech Stack

- Java
- Servlets
- JSP
- Apache Tomcat
- HTML
- CSS

## Architecture

- MVC
- DAO Pattern

## Current Storage

- In-memory ArrayList

## Future Improvements

- JDBC + MySQL
- JSTL & Expression Language
- Session Management
- Authentication
